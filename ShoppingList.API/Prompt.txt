Create an API (ShoppingList.API), using the Regira packages, which offers services to run a Shopping list. 

A shopper can select activate/deactivate articles on the shopping list.
An article can have multiple categories and shoppers can filter them easily, text search included.
A category can have multiple parent/child categories.
Each shopper can have multiple lists.

- Make sure the project builds.
